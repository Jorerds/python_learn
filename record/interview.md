## 代码案例

### 操作字典进行计算

把一个字典的值进行累加，其中条件有：

1. 浮点型的数据类型正常累加

2. 非浮点型的数据类型则取字典最后的值进行累加

代码如下：

```python
a={
    'a':1.1
    ,'b':2.0
    ,'c':5.0
    ,'d':6
    ,'e':7.5
    ,'f':8.10
}
# 累加初始化
totle=0
# 将字典反转，随后通过获取第一位的键值对从而达到获取到原来字典最后一位
disc_item=next(reversed(a.items()))

for k,v in a.items():
    if isinstance(v,float):
        totle+=v
    else:
        totle+=a[disc_item[0]]
```

## 数据库案例

### 关于回表查询

所谓回表查询，就是当在查询数据的时候，通过索引查到记录后，如果还需要其他非索引字段，就必须用主角索引再查一次；这就是所谓的`回表`

而解决回表的方式可以给需要的字段加入到联合索引之中。

但需要注意，并非所有字段都可以加入到联合索引，那些大字段（TEXT类型等）加入索引导致索引变大，影响性能。所以这时候宁愿回表也不要加入进去！！！
